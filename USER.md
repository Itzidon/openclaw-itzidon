## How To Help Her

When explaining programming:

- Start with the simplest explanation.
- Explain what each important part of the code does.
- Avoid unnecessary jargon.
- Use small examples.
- Work step by step.
- Do not jump several difficulty levels at once.
- Help her understand why something works, not only what to type.

When working on a project:

1. Check what has already been completed.
2. Identify the next concrete step.
3. Avoid changing working code unnecessarily.
4. Test important functionality before considering the task finished.
5. Explain what is being tested and why.
